## 1. 小程序名称建议

**微信命名的一般规则（请以后台实际提示为准）：**名称长度有上下限（通常为 4–30 个字符，1 个汉字算 2 个字符，即约 2–15 个汉字）；全平台唯一，不能与已有公众号 / 小程序重名；不能含「最」「第一」「官方」等夸大或误导用词；不能使用他人商标或知名品牌（如 Keep、薄荷、华为运动健康等）；个人主体每年可改名次数有限，提交前想清楚。

| # | 备选名 | 理由 |
|---|---|---|
| 1 | **练迹** | 「训练的足迹」，两个字好记，和「训练日历 + 历史记录」的核心功能贴合，没有夸大词 |
| 2 | **练迹本** | 在「练迹」基础上加「本」，更像一个记录工具；如果「练迹」已被占用可以用这个 |
| 3 | **组次本** | 直接点出「记录组数和次数」，健身人一看就懂，偏工具属性，审核容易理解用途 |
| 4 | **举铁手记** | 「举铁」是力量训练的常用说法，「手记」体现个人记录，语气轻松，有辨识度 |
| 5 | **训练手账** | 描述性最强、最直白，适合按「训练记录」搜索的用户；缺点是词比较通用，被占用的可能性较大 |

> **请自查（重要）：**
> 1. **是否已被占用**：后台填名称时会实时校验是否重名；也可以先在微信里搜一下同名小程序 / 公众号。
> 2. **是否撞商标**：以上名称我**没有**做商标检索。请到国家知识产权局「中国商标网」（sbj.cnipa.gov.cn）查询第 9 类（软件）、第 41 类（健身 / 体育服务）、第 42 类（软件服务）等相关类别，避免和已注册商标相同或近似。
> 3. 名称应和实际功能一致（这是一个训练记录工具），不要使用「教练」「减脂」「减肥」「医疗」「健康管理」这类可能让审核认为你在提供专业指导或医疗服务的词。

## 3. 类目建议

### 推荐思路
- **首选：「工具」大类下，与记录 / 效率相关、且不需要资质的二级类目**（例如名称类似「效率」「记账」「备忘录」等的二级类目；具体叫什么、个人主体能不能选，**以后台实际可选项为准**）。
  - 理由：这个小程序本质上是**个人记录工具**——纯本地存储、无服务器、无内容发布、无交易、无社交。按工具类提交，和功能描述最一致，一般也不需要额外资质。
- **备选：「体育」大类下面向个人、不涉及培训 / 赛事 / 场馆经营、且对个人主体开放且免资质的二级类目**（如果后台有类似「体育 > 健身」或「运动记录」之类的选项，并且选择时**没有**要求上传资质文件，可以考虑；**确切名称以后台实际可选项为准**）。
  - 理由：和「健身」主题更贴近，用户和审核更容易理解。但体育类下不少二级类目面向培训、场馆、赛事、票务，需要企业主体或许可证，**个人主体能选的范围可能很窄**。

### 怎么判断能不能选
在后台选类目时，如果某个类目提示需要上传资质（营业执照、许可证、医疗相关证明等）或提示「个人主体不可选」，就**不要选**。只选**勾上以后不需要上传任何文件**的类目。

### 需要避开的类目方向
| 避开的方向 | 原因 |
|---|---|
| 医疗、医疗服务、健康管理 / 医疗健康类 | 通常需要医疗相关资质，个人主体一般不开放；本小程序虽然记录体重 / 体脂，但**不是**医疗或健康诊断工具 |
| 体育培训、在线课程、教育类 | 通常需要办学 / 培训相关资质，而且本小程序不提供课程或教练服务 |
| 体育场馆、赛事、票务、运动服务预约 | 需要经营资质，与功能不符 |
| 社交、内容资讯、视频 | 本小程序没有用户发布内容和社交功能，选这些类目反而会招来额外审核要求 |
| 商业服务、电商、生活服务中涉及交易的类目 | 无交易，不相关，且多需企业主体 |

> 类目会影响审核员对你功能的预期：选什么类目，提交时的功能描述就要和它对得上。

底部有 3 个标签：日历 / 动作库 / 身体数据。

一、训练日历（底部「日历」，首页）
1. 打开小程序即进入本月日历，今天默认选中；点左右箭头切换月份，点「今天」回到本月。
2. 有已完成训练的日期下方有圆点；点击该日期，下方显示当天的训练摘要卡；点摘要卡进入「训练详情」。
3. 在训练详情页可以点「编辑训练」修改，或点「删除这条训练」（会二次确认）。

1. 在日历页点右下角「+」按钮，或在今天的空状态里点「开始训练」，进入训练编辑页。
   选中过去的日期时可点「补录训练」；未来日期不能新建。
2. 点「+ 添加动作」进入选择动作页，可搜索或筛选，勾选一个或多个动作后添加到训练。
3. 每个动作下可调整重量（kg）和次数，勾选该组完成；点「+ 加一组」加组；长按某一组可设为热身组或删除；动作右侧「⋯」可写动作备注、调整顺序、替换或删除动作。
4. 改动会自动保存在本机。点「完成训练」（至少完成 1 组）后进入训练详情，回到日历该日期会出现圆点。
5. 如中途离开，日历页会显示「未完成训练」横幅，点「继续」可回到编辑。

三、身体数据（底部「身体数据」）
1. 点右下角「+」进入记录页，填写日期、体重（必填）、体脂率 / 腰围 / 备注（选填），点「保存」。
2. 返回后可在「图表」视图切换体重、体脂率、腰围指标和时间范围，查看折线图；切换到「日历」视图按日期查看记录，可「编辑」或「补录这天」。
3. 点击记录可编辑，长按记录可删除（会二次确认）。

四、动作库（底部「动作库」）
1. 列表展示 284 个动作，按部位分组，可在顶部搜索框输入中文或英文名搜索。
2. 点「肌群」「器械」按钮可筛选。
3. 点任一动作进入详情，查看目标肌群、次要肌群和动作步骤；点「加入当前训练」可把动作加入正在进行的训练（没有训练时会自动新建今天的训练）。
4. 动作库列表底部「关于 / 数据来源」页面列出了动作文字资料的开源出处（openGym，AGPL-3.0 许可）及许可证全文。

【其他说明】
- 本小程序不调用定位、相册、相机、麦克风、剪贴板、通讯录等任何隐私相关接口，不获取微信头像昵称或手机号，不包含第三方 SDK，没有分享、社交、评论或付费功能。
