# 训练模板 1.0.2 · 实装说明

> 叠回已含饮食模块的 main。饮食 Tab、页面、公式和存储键保持原样。

当前 Git 历史里没有上一版模板实现（`preset-templates.js`、模板页、repo 辅助函数都不在任何提交里）。这次按 1.0.2 的能力在现有力量训练模型上重新接上，没有重写饮食。

## 能做什么

- 训练首页日期标题右侧有「模板 ›」。点「+」时，菜单里也有「训练模板」；补录菜单里有「从模板补录」。
- 训练编辑页顶部有「训练模板 ›」。
- 精选 6 套，每套 4 个动作：居家全身自重，以及健身房的胸、肩、背、腿、手臂。
- **复制**：把精选存进本机「我的模板」（键 `fit_templates`）。不改当天训练。可以改名称、删除。不能改动作组成。
- **套用**：
  - 从首页进来：为所选日期新建一条力量草稿，名称用模板名，4 个动作各带 1 个空组。
  - 从训练编辑进来：把这 4 个动作追加到当前这条训练，然后回到编辑页。
- 已经有未完成的力量草稿时，新建套用会先问「继续 / 放弃」，规则和「新建力量训练」一样。
- 未来日期只能浏览，不能套用。

## 自测

在 `miniprogram/` 下：

```bash
node --test tests/repo.templates.test.js tests/repo.diet.test.js
node scripts/smoke-pages.js
node ../qa/check-requires.js
```

冒烟覆盖的路径：

1. 训练首页「模板 ›」→ 精选 6 套 → 打开「居家全身自重」→ 复制 → 套用 → 进入编辑页，4 个动作，训练名是模板名。
2. 接着打开饮食页：没有计划时仍在「计划」空态；本机模板和刚套用的训练都还在。
3. 训练编辑（还没加动作的草稿）→ 训练模板 → 健身房 · 胸 →「追加到当前训练」→ 回到编辑页，动作为杠铃卧推、哑铃上斜卧推、哑铃飞鸟、绳索上胸夹胸。

微信开发者工具里可以再点一次：饮食 Tab 能进；训练首页和编辑页都能进模板并套用。本环境没有开发者工具，页面冒烟用的是假 `wx`，不包含真机布局。

## 已知限制

1. 精选动作 id 绑在当前动作库上。某个 id 以后被删掉时，套用整单失败，不会写入一半。
2. 「我的模板」只能改名称和删除，不能增删动作。要换动作，套用之后在训练里改。
3. 套用生成的是空组（重量、次数待填）。补录日也不会自动打勾。
4. 同一时间仍然只能有一条力量草稿。有草稿时，从首页套用要先继续或放弃。
5. 不提审、不发布。
