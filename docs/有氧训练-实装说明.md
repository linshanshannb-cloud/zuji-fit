## 数据结构

存储键：`fit_aerobics`（数组）。单条示例：

```json
{
  "id": "a_…",
  "status": "completed",
  "date": "2026-10-25",
  "activityType": "elliptical",
  "activityName": "椭圆仪",
  "durationMin": 30,
  "estimatedKcal": 225,
  "kcalSource": "reference",
  "note": "",
  "createdAt": 0,
  "updatedAt": 0
}
```

- `activityType=custom` 时 `activityName` 必填（≤20 字）。
- 热量：`round(每小时参考 × durationMin / 60)`；手改后 `kcalSource=user_override`。
- 与力量 draft **分轨**，不互斥。

## 开发者工具冒烟步骤

1. 用微信开发者工具打开工程目录 **`miniprogram`**（或项目根，以 `project.config.json` 为准）。
2. 编译后进入 **训练** Tab。
3. 选今天 → 点右下角 **+** → 选「有氧训练」→ 选「椭圆仪」→ 时长 30 → 应见约 **225 kcal（估算）** → 保存。
4. 回到日历：当日卡片出现带「有氧」标签的卡片；月历格子内出现有氧类型标签（橙字浅底）。
5. 同日再完成或已有力量训练时：格子内部位灰标签 + 有氧橙标签并存；下方两张卡片并列。
6. 点有氧卡片 → 详情 → 编辑改热量 → 应显示「已手动调整」；删除需二次确认。
7. 选未来日期 → 新建应 Toast 拒绝。
8. （可选）选「自定义」空名称保存应阻断；填「战绳」可保存。
