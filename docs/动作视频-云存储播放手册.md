# 动作视频 · 云存储播放手册（组迹小程序）

> 适用版本：体验版 0.3.0 起。AppID `wxd000e3fb6e804ce0`。
> 结论（**0.3.0 已在真机 iPhone 验证可播放**）：动作视频放云存储，存储权限用**自定义规则**，详情页用 `getTempFileURL` 拿 **https 地址直接给 `<video>`** 播放。

## 1. 现状架构

| 项 | 值 |
|---|---|
| 云开发环境 | `cloud1-d8gn4xfqredd566d1` |
| 存储路径 | `anim/<id>.mp4`（id 为 4 位动作编号，如 `0025`） |
| fileID 前缀 | `cloud://cloud1-d8gn4xfqredd566d1.636c-cloud1-d8gn4xfqredd566d1-1511089058/anim/` |
| 公开下载域名 | `https://636c-cloud1-d8gn4xfqredd566d1-1511089058.tcb.qcloud.la/anim/<id>.mp4` |
| 存储权限 | 自定义安全规则 `{"read": true, "write": "resource.openid == auth.openid"}` |
| 数据字段 | `data/exercises.json` / `data/exercises.js` 里每个动作的 `video`（完整 fileID）、`poster`（主包封面 `/assets/video-posters/<id>.jpg`） |
| 分包 | 无（packageVideoA/B/C 已删除，主包约 1.42MB） |

**初始化**（`app.js`，`onLaunch` 第一行）：

```js
if (wx.cloud) wx.cloud.init({ env: 'cloud1-d8gn4xfqredd566d1', traceUser: true });
```

**详情页播放逻辑**（`pages/exercise-detail/exercise-detail.js`）：

1. 进页面先显示主包封面（`poster`，没有就用线稿）。
2. `wx.cloud.getTempFileURL({ fileList: [fileID] })` 拿到 https 地址，设置为 `<video src>`（`autoplay loop muted`，不显示控件）。地址在本次打开期间缓存。
3. 拿地址失败或 https 播放报错时，自动退回 `wx.cloud.downloadFile`，用本地路径再试一次。本地文件用 `saveFile` 持久缓存，缓存 key 为 `cloudVideoCache_v2`。
4. 两条路都失败时弹**诊断弹窗**：errMsg、src、本地文件大小（`getFileInfo`）、fileID，然后退回封面。
5. 点视频回到封面，再点重新播放。

## 2. 踩坑时间线

| 版本 | 方案 | 真机现象 / 报错 | 原因 | 结论 |
|---|---|---|---|---|
| 0.2.0 | mp4 放分包，`<video src>` 用分包路径 | `MEDIA_ERR_SRC_NOT_SUPPORTED` | iOS `<video>` 不认代码包路径 | ❌ |
| 0.2.1 | 分包 mp4 复制到 `USER_DATA_PATH` 再播 | `readFile:fail …` | iOS 上文件管理器（FileSystemManager）读不到分包文件 | ❌ |
| 0.2.2 | 改成动图 WebP 放分包 | 动图没进代码包（分包只剩约 230KB） | 代码包不打包 `.webp` | ❌ |
| 0.2.3 | WebP 改名 `.png` | `getLocalImgData:fail` | iOS 读分包图片失败（格式也对不上） | ❌ |
| 0.2.4 | 真 GIF 放分包 | `getLocalImgData:fail` | 同上，和格式无关 | ❌ |
| 0.2.5 | 路径补开头的 `/` | 同上 | 运行时本来就补了 `/`，不是原因 | ❌ |
| 0.2.6 | 诊断：1 个 GIF 放主包 | — | 主包上限 **2MB**，放不下 24 个 | 不可行 |
| 0.2.7 | 云存储 + `<video src="cloud://…">` | 黑屏后 `MEDIA_ERR_NETWORK` | 下载域名返回 403（见下） | ❌ |
| 0.2.8 | `getTempFileURL` 拿 https 地址 | `MEDIA_ERR_NETWORK`；外网访问也是 403 | 「所有用户可读」预设权限下，`tcb.qcloud.la` 返回 403 空内容 | ❌ |
| 0.2.9 | `downloadFile` 拿本地路径 | 先报 `downloadFile:fail file data is empty`（错误码 603302）；改权限后下载成功，但 `wxfile://` 报 `SRC_NOT_SUPPORTED` | ① 403 空内容；② iOS `<video>` 播本地 wxfile 路径不稳定 | ❌ |
| **0.3.0** | **自定义读规则 + https 地址直接播**，downloadFile 兜底 | **真机 iPhone 可播放**（用原云端文件，没覆盖成 anim_v2） | — | ✅ |

**最终根因**：

1. **存储预设权限「所有用户可读」**：下载域名返回 403 空内容，导致 `MEDIA_ERR_NETWORK` 和 `file data is empty`。改成自定义规则 `{"read": true, ...}` 后解决。
2. **iOS `<video>` 播本地路径（分包路径或 wxfile）不稳定**：报 `SRC_NOT_SUPPORTED`。改成 https 地址流式播放。

编码不是原因：原文件是 H.264 Main@3.1、yuv420p、moov 在前，iOS 原生支持。分包里的 Baseline 版本当时同样报错。

**其他结论**：

- 微信开发者工具 CLI **不能上传云存储**（`cli cloud` 只有 `env` 和 `functions`），只能在控制台手动上传。
- 主包上限 2MB，分包每个 2MB，总包 20MB。

**备用规格 anim_v2**：最保守的 Baseline 版本。公司电脑 `Desktop\cloud-upload\anim_v2\`，盒子上 `/workspace/cloudanim_v2/`。目前没用上，某台设备播不了时可以用它覆盖 `anim/`。

## 3. 报错速查表

| 报错 | 含义 | 怎么查 | 怎么修 |
|---|---|---|---|
| `MEDIA_ERR_SRC_NOT_SUPPORTED` | 播放器不接受这个地址或格式 | 看弹窗里的 src：是分包路径或 `wxfile://` 吗？用 `ffprobe` 看编码 | 改用 https 地址；编码仍可疑就换 anim_v2 规格 |
| `MEDIA_ERR_NETWORK` | 网络地址拿不到数据 | 浏览器打开 `https://636c-…tcb.qcloud.la/anim/<id>.mp4`，看是不是 403 | 存储权限改成自定义规则 `{"read":true,...}`，关掉防盗链 |
| `downloadFile:fail file data is empty`（603302） | 下载回来是空内容（403 或 304） | 同上：外网访问返回 403、content-length 为 0 | 同上 |
| `getTempFileURL status≠0` / `STORAGE_FILE_NONEXIST` | 文件不存在，或 fileID 写错 | 控制台 → 存储，看 `anim/<id>.mp4` 是否存在、名字是否一致 | 补传文件，或修正数据里的 fileID |
| `getLocalImgData:fail` | iOS 读不了分包里的图片 | — | 图片和视频不要放分包，放主包（受 2MB 限制）或云存储 |
| `readFile:fail …` | iOS 读不了分包文件 | — | 同上 |
| CLI `40001 invalid credential` | 开发者工具登录失效 | — | 在那台电脑扫码重新登录（会顶掉另一台） |
| 代码包体积表里分包大小异常小 | 文件类型被打包排除（如 `.webp`） | 看 CLI 上传输出的体积表 | 换成代码包支持的格式 |

## 4. 新增动作视频 SOP

### 4.1 素材要求

- **只能用自己生成的素材**（libtv 生成，形象自制）。**严禁使用 openGym / Gym visual 的任何 media**（图片、动画、视频）。
- 方形，建议 640×640；5 秒左右的循环动作，不需要声音。

### 4.2 转码（默认用 Main 规格，已验证可播）

```bash
ffmpeg -y -i 原片.mp4 -an -c:v libx264 -profile:v main -level 3.1 -pix_fmt yuv420p \
  -crf 23 -preset slow -movflags +faststart <id>.mp4
```

备用的最保守规格（anim_v2 用的这条）：

```bash
ffmpeg -y -i 原片.mp4 -map 0:v:0 -an -map_metadata -1 -c:v libx264 -profile:v baseline -level 3.1 \
  -pix_fmt yuv420p -r 24 -g 24 -bf 0 -crf 22 -preset slow -vf "scale=640:640" \
  -movflags +faststart -brand mp42 <id>.mp4
```

自检：

```bash
ffprobe -v error -show_entries stream=codec_name,profile,level,pix_fmt,width,height,r_frame_rate -of compact <id>.mp4
```

预期：h264、Main 或 Baseline、level 31、yuv420p、宽高为偶数。单个文件尽量小于 1MB。

### 4.3 命名与上传

- 文件名：`<动作id>.mp4`（4 位数字，与数据里的 `id` 一致），不能有中文或空格。
- 微信开发者工具 → 云开发 → 存储 → 进 `anim/` → 上传，同名文件会被覆盖。
- 上传后用浏览器打开 `https://636c-cloud1-d8gn4xfqredd566d1-1511089058.tcb.qcloud.la/anim/<id>.mp4`，应能直接播放或下载（返回 200）。

### 4.4 修改数据

在 `data/exercises.json` **和** `data/exercises.js` 两个文件里，给对应动作加上或修改字段：

```json
"video": "cloud://cloud1-d8gn4xfqredd566d1.636c-cloud1-d8gn4xfqredd566d1-1511089058/anim/<id>.mp4",
"poster": "/assets/video-posters/<id>.jpg"
```

- 封面放主包 `assets/video-posters/<id>.jpg`（建议小于 40KB，注意主包 2MB 上限）。没有封面就会显示线稿。
- ⚠️ `scripts/build-data.js` 会从 `exercises.json` 重新生成 `exercises.js`。重跑之后，`illustration` 和 `poster` 可能变回不带开头 `/` 的路径。运行时 `absPath()` 会自动补上，不影响使用，但要检查 `video` 字段是否保留了完整 fileID。
- 本地测试：`for t in tests/*.test.js; do node $t || echo FAIL $t; done`

### 4.5 上传体验版（CLI）

cli.bat 路径：两台电脑都是 `D:\微信web开发者工具\cli.bat`（脚本里通过遍历 `D:\` 下的子目录查找）。描述**用英文**，中文经过 cli.bat 可能会乱码。

保存为 `up.ps1`（**UTF-8 带 BOM**）。家里电脑把路径换成 `C:\Users\Administrator\...`：

```powershell
$cli = Get-ChildItem -Path "D:\" -Directory | ForEach-Object { Join-Path $_.FullName "cli.bat" } | Where-Object { Test-Path $_ } | Select-Object -First 1
$psi = New-Object System.Diagnostics.ProcessStartInfo
$psi.FileName = $cli
$psi.Arguments = 'upload --project "C:\Users\MX20426\fitness-miniapp\miniprogram" -v 0.3.1 -d "add exercise videos"'
$psi.UseShellExecute = $false; $psi.RedirectStandardOutput = $true; $psi.RedirectStandardError = $true
$p = [System.Diagnostics.Process]::Start($psi)
$o = $p.StandardOutput.ReadToEndAsync(); $e = $p.StandardError.ReadToEndAsync()
$p.WaitForExit(600000) | Out-Null
$o.Result; $e.Result; "EXIT: $($p.ExitCode)"
```

运行：`powershell -ExecutionPolicy Bypass -File "C:\Users\MX20426\up.ps1"`

查环境：把参数换成 `cloud env list --appid wxd000e3fb6e804ce0`。

检查输出的体积表：主包要小于 2MB，退出码为 0。

## 5. 电脑与登录注意事项

- **开发者工具登录互斥**：在一台电脑登录，会让另一台的云开发凭证失效（CLI 报 `40001 invalid credential`）。上传或查云环境请在**当前已登录的那台**操作（目前是公司电脑 `C:\Users\MX20426\fitness-miniapp`）。
- 家里电脑工程：`C:\Users\Administrator\fitness-miniapp\miniprogram`；公司电脑工程：`C:\Users\MX20426\fitness-miniapp\miniprogram`。改动要三份同步（盒子 `/workspace/fitness-miniapp` + 两台电脑）。
- **CopyFromBox 传大于约 10MB 的文件会失败**（提示电脑暂时连不上），要拆成约 2MB 的 zip 分批传，再用 PowerShell `Expand-Archive` 解压。
- PowerShell 注意事项：
  - 不要用 `&&`，路径加引号；
  - 含中文的 `.ps1` 要存成 UTF-8 带 BOM；
  - 内联 `-Command` 里的 `$变量` 会被外层吃掉，复杂逻辑写成 `.ps1` 文件再执行。
- 任何需要扫码或授权的步骤，只能本人在电脑前操作。
