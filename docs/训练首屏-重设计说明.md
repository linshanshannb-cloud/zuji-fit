# 训练 Tab 首屏重设计说明（v0.5 日历压缩 + 当日汇总）

日期：2026-10-25　范围：`pages/calendar/*`、`components/month-calendar/*`、`utils/daymark.js`、`utils/date.js`（仅新增纯函数）

## 1. 问题（iPhone 实拍反馈）

| # | 现象 | 根因（代码） |
|---|---|---|
| P1 | 每周一行很高，6 行月历占满首屏 | `.rich { height: 148rpx }` × 6 行 = 888rpx，加表头/星期/图例 ≈ 1060rpx；导航栏后几乎没有剩余高度 |
| P2 | 格子内「胸」「跑步机…」极小 | `.ctag { font-size: 16rpx }`（iPhone 实际约 8pt），每个标签单独一行，最多 4 行 |
| P3 | 有训练日不明显 | 训练日与普通日底色相同，仅靠灰底小标签区分；数字字重相同 |
| P4 | 所选日训练卡片被挤到底部只露一点 | 日历过高；卡片本身每张又带一行 44rpx 大数字，多张卡片时摘要分散 |

## 2. 方案

### 2.1 月历压缩：默认周视图 + 展开/收起
- **默认周视图**：只显示「所选日所在周」一行（周一起）。表头 `2026年10月 [今天]  ‹ ›` 不变。
- **展开/收起**：日历底部一行左侧是图例，右侧是「展开月历 ▾ / 收起 ▴」（88rpx 点击高度）。展开后为 6 行月视图，收起回到所选日所在周。
- **行高**：训练页（rich）每行 **100rpx**（原 148rpx；= 上边距 6 + 日期 40 + 2×(间距 2 + 标签 24)）；体重页（value 变体）不变。
- **切换**：
  - 周视图下 ‹ › / 左右滑动 = 前后一周，所选日同步移动 7 天（保持同一星期几），年月跟随所选日变化，**可自然跨月/跨年**（如 9/28–10/4 一行里同时出现两个月的日期，均正常显示标签，不置灰）。
  - 月视图下 ‹ › / 左右滑动 = 前后一月（原行为）。
  - 「今天」：两种视图都回到今天并选中。
  - 月视图中翻到别的月份再收起：回到所选日所在周（年月重置为所选日月份）。
- **数据范围**：`info` 改为按「所选日所在月的 6×7 网格」首尾日期构建（原来只构建当月 1 日–月末）。周视图中跨月的那几天因此也有标签；月视图中非本月格子仍隐藏标签（与原来一致）。

### 2.2 训练日一眼可见 + 标签可读
- **训练日格子**：整格圆角浅橙底 `#FFE4D6`（左右各缩 3rpx，圆角 16rpx），日期数字加粗 `#111`。
- **标签合并为最多两行**（纵向并排，力量在上、有氧在下，同格同时出现；仍然禁止双色点）：
  - 力量行：部位短名用「·」连接，如「胸·背」「背·臂·腿」（最多 3 个部位，沿用 `CELL_MAX_PARTS`）。白底、`#111` 字。
  - 有氧行：第一个有氧类型（已截断 ≤4 字，如「跑步机…」）；同日多种有氧时显示「跑步+1」。白底、`#C94412` 字。
  - 字号 **20rpx**（原 16rpx），行高 24rpx，字重 600。
- **休息日**：保留灰蓝「休」圆标，不加底色。
- **选中**：日期数字黑底白字圆（40rpx）；训练日选中时同时保留浅橙底，信息不丢。
- **今天**：日期数字 `#FF5A1F` 加粗；若今天同时被选中则为黑圆（与原规则一致）。
- **图例**（一行）：`[胸] 力量部位　[跑步] 有氧　(休) 休息　● 选中`，样例使用与格子相同的样式（浅橙底上的白标签）。

### 2.3 所选日汇总卡（日历正下方）
标题行：`10月15日 周四` + 状态标签（已完成 / 休息日）。有训练时紧跟一张汇总卡：

```
┌──────────────────────────────────────────┐
│ 总时长                        75 分钟     │ ← 大号数字（仅 >0 时显示）
│ ──────────────────────────────────────── │
│ [力量]  胸 · 背 · 臂                       │ ← 部位大字 36rpx
│  5        18        3,240                 │ ← 44rpx 数字
│  动作      组        容量 kg               │
│ ──────────────────────────────────────── │
│ [有氧]  跑步 · 爬楼机                       │
│  45        420                            │
│  分钟      kcal（估算）                     │
└──────────────────────────────────────────┘
```
- 力量与有氧分别汇总当天所有记录（多次训练相加）；只有一种时只显示一块。
- 部位取当天全部已完成正式组排名（`daymark.dayParts`，与格子同一套规则，不截断）。
- kcal：任一条为手动调整时标注「kcal（含手改）」，否则「kcal（估算）」。
- 下方「记录」列表保留每条训练/有氧卡片（点击进详情），但去掉卡片里重复的大数字行，改为一行小字摘要（`5 动作 · 18 组 · 3,240 kg` / `300 kcal · 估算`，时长仍在卡片右上），力量卡仍列出前 3 个动作及最佳组。
- 空态（今天/过去/未来/休息日）、草稿横幅、「+ 新建有氧」、FAB 全部保留，逻辑不变。

## 5. 取舍

1. **周视图翻周会移动所选日**（±7 天，同星期几）。好处：「周视图 = 所选日所在周」这一规则始终成立，汇总卡永远对应可见的那一行；代价是浏览历史周时汇总卡随之变化。也考虑过「周锚点与所选日分离」，但会出现「所选日不在可见行」的状态，需要额外提示，放弃。
2. **展开/收起状态不持久化**：每次进入页面默认周视图。要求「不改存储」，且默认周视图正是本次目标；`fit_ui_prefs` 可以存，但留待产品确认后再加。
3. **格子标签合并为两行**（原来每个标签一行、最多 4 个 + `+N`）。100rpx 行高只放得下数字 + 两行 20rpx 文字；力量部位合并为一行「胸·背」，多种有氧折叠为「跑步+1」。完整信息在下方汇总卡。
4. **只用整格底色标记训练日**，不区分力量/有氧底色（避免双色），类型靠两行标签的字色区分（力量黑字、有氧 `#C94412`）。
5. **卡片去掉大数字行**：大数字集中在汇总卡，避免同一屏两套大号统计；单条记录仍可点进详情看全部。
6. 月视图非本月格子仍隐藏标签（与原逻辑一致，避免边缘格子信息过密）；周视图跨月日期正常显示。
