## B. 功能验收（对照 PRODUCT_SPEC 核心流程）

### B1 训练日历（P1）
| # | 标准 | □ |
|---|---|---|
| B1.1 | 本月月历可左右切月；「今天」回到本月并选中今天 | □ |
| B1.2 | 有已完成训练的日期显示强调色圆点；选中日有摘要卡 | □ |
| B1.3 | 存在草稿时任意选中日都显示草稿横幅，可「继续」 | □ |
| B1.4 | 选中未来日期时新建按钮置灰，toast 提示不能新建 | □ |

| # | 标准 | □ |
|---|---|---|
| B2.1 | 新建草稿 → 加动作 → 录多组（重量 / 次数 / 热身 / 勾选）→ 完成训练进入详情 | □ |
| B2.2 | 草稿自动保存；杀进程重开后可继续 | □ |
| B2.3 | 已有草稿时再新建：弹窗「继续 / 放弃」文案 ≤ 4 字 | □ |
| B2.4 | 查看、编辑、删除已完成训练；删除有二次确认 | □ |
| B2.5 | 补录过去训练：组默认已完成；无 `startedAt` 时不显示时长 | □ |
| B2.6 | ± 长按不误触（`catchlongpress`） | □ |
