# 健身小程序 v1 · 设计规范（DESIGN）

- 负责人：极简设计师　更新：2026-10-17（UTC+8）
- 适用：微信原生小程序 v1，四个模块：训练日历 / 训练管理 / 身体数据 / 动作库
- 交互规则、校验、空状态和失败状态的完整说明见 `../spec/PRODUCT_SPEC.md`；字段以 `../spec/DATA_MODEL.md` 为准
- 线框图：`wireframes/*.svg`（13 张，375×812），浏览器打开 `wireframes/index.html` 并排预览。线框里的**蓝色小字是设计标注**，不是界面元素
- 尺寸换算：设计稿 375 宽，**1px = 2rpx**。本文所有尺寸写 rpx，括号里是设计稿 px

## 1. 设计原则

1. **少即是多**：白底、黑字、灰色层级，整个页面只用一个强调色。一屏只有一个主操作。
2. **数字优先**：重量、次数、体重都是主角，用大字号和等宽数字（`font-variant-numeric: tabular-nums`）显示，标签退到灰色小字。
3. **单手可用**：录入训练时手机常握在一只手里。主操作固定在底部拇指区，点击区域 ≥ 88rpx（44px），录入行高 ≥ 96rpx。
4. **纯文字也要好看**：多数动作无图，用字号对比、留白和肌群标签撑起层级；无图用文字占位，试点 20 可用极简线稿示意图（见 `ILLUSTRATION.md`）。
5. **克制的反馈**：删除组或动作时用「撤销」代替确认弹窗。删除整次训练或身体记录这类后果严重的操作，才弹二次确认。
6. **遵循微信习惯**：底部原生 tabBar、右上角胶囊不遮挡、系统 `showModal` / `showActionSheet` / `showToast` 优先，不自造弹窗。

## 2. 设计 Token

> 下面的 CSS 变量是规范，建议写在 `app.wxss` 的 `page {}` 里，代码中引用变量，不要直接写色值。

### 2.1 颜色

黑白灰，加一个强调色 **活力橙 `#FF5A1F`**。

| Token | 色值 | 用途 |
|---|---|---|
| `--c-ink` | `#111111` | 主文字、主按钮底色、选中态（选中日、选中 chip） |
| `--c-text-2` | `#666666` | 次要文字（对白底对比度 5.7:1） |
| `--c-text-3` | `#8C8C8C` | 辅助文字、标签名、坐标轴（3.4:1，只用于 ≤ 24rpx 的辅助信息） |
| `--c-placeholder` | `#BBBBBB` | 输入占位、未来日期、chevron |
| `--c-line` | `#E5E5E5` | 分割线、描边 |
| `--c-bg-2` | `#F7F7F7` | 搜索框、分组标题、分段控件底、占位块 |
| `--c-white` | `#FFFFFF` | 页面底色、卡片 |
| `--c-accent` | `#FF5A1F` | 强调：训练日圆点、今天日期、折线、悬浮按钮、完成勾选、选中 tab |
| `--c-accent-weak` | `#FFF1EB` | 强调浅底：草稿横幅、「草稿」标签底 |
| `--c-danger` | `#E5484D` | 删除文字、校验错误 |
| `--c-mask` | `rgba(0,0,0,.35)` | 弹层遮罩 |
| `--c-disabled` | `#E5E5E5` | 禁用按钮底色、禁用悬浮按钮（走查补充） |
| `--c-check` | `#CCCCCC` | 未勾选圆圈描边（走查补充） |
| `--c-ph-big` | `#D6D6D6` | 动作详情大占位字（走查补充） |

> canvas 和 `wx.showModal({confirmColor})` 读不到 CSS 变量，请在 `utils/tokens.js` 里放一份同值的 JS 常量，不要在各处写死色值。

强调色使用规则：
- `#FF5A1F` 对白底的对比度是 3.1:1，满足**图形元素和大号文字**（WCAG 3:1），**不用于 ≤ 28rpx 的正文**。
- 主按钮用 `--c-ink` 黑底白字（对比度 18:1），强调色只放在悬浮按钮、完成勾选、折线和日历标记上。这样一屏的橙色不超过 2–3 处。
- 不使用渐变、阴影色或第二个彩色。图表只用一条强调色折线。
- 现有代码 `DEV_NOTES.md` 里用的也是 `#FF5A1F`，保持不变。

### 2.2 字体与字号

字体：系统字体 `-apple-system, "PingFang SC", "Helvetica Neue", sans-serif`。数字统一加 `font-variant-numeric: tabular-nums`。

| Token | 字号 rpx（px） | 字重 | 行高 | 用途 |
|---|---|---|---|---|
| `--fs-display` | 80（40） | 700 | 1.1 | 身体数据当前值（68.4） |
| `--fs-h1` | 48（24） | 700 | 1.25 | tab 页大标题、详情页日期 |
| `--fs-h1-detail` | 56（28） | 700 | 1.25 | 动作详情页名称 |
| `--fs-nav` | 34（17） | 600 | 1.3 | 二级页导航标题、区块标题、卡片标题 |
| `--fs-num` | 34（17） | 600 | 1 | 步进器里的数字 |
| `--fs-body` | 30（15） | 400 | 1.5 | 正文、列表主文字（列表主文字用 32 / 16） |
| `--fs-sub` | 26（13） | 400 | 1.4 | 次要信息、chip 文字、分段控件 |
| `--fs-caption` | 22（11） | 400 | 1.4 | 标签、坐标轴、统计项名称 |
| `--fs-stat` | 44（22） | 700 | 1.2 | 摘要卡 / 详情页统计数字（2026-10-17 走查补充） |
| `--fs-list` | 32（16） | 600 | 1.4 | 列表主文字、按钮文字、表单标签（走查补充） |
| `--fs-sm` | 28（14） | 400 | 1.5 | 步骤正文、单位、toast、次要列表行（走查补充） |
| `--fs-err` | 24（12） | 400 | 1.4 | 校验错误、空状态副文案、只读提示条（走查补充） |
| `--fs-tab` | 20（10） | 400/600 | 1 | tabBar 文字（原生） |

规则：一屏最多 3 级字号；层级优先用字重和颜色区分，其次才是字号。

### 2.3 间距与栅格

- 基础单位 **8rpx**。可用值：`8 / 16 / 24 / 32 / 48 / 64 / 96`（`--sp-1` … `--sp-7`）。
- 页面左右边距：**32rpx（16px）**。卡片内边距 32rpx。
- 列表项高度：单行 96rpx，双行 120rpx（动作库为 136rpx）。
- 区块之间：48rpx；区块标题与内容：24rpx。
- 栅格：内容宽 686rpx（343px），常用 2 列（统计、信息格，列间距 0，竖向 hairline 分隔）或 3 列（统计数字），日历为 7 等分（每列 98rpx）。

### 2.4 圆角与线

| Token | 值 rpx（px） | 用途 |
|---|---|---|
| `--r-tag` | 8（4） | 标签 |
| `--r-control` | 16（8） | 按钮、输入框、步进器、搜索框、toast、分段控件 |
| `--r-card` | 24（12） | 卡片、弹层顶部两角 |
| `--r-pill` | 999 | chip、胶囊、悬浮按钮（圆） |

线：
- **分割线用 hairline**（物理 1 像素）：`1px` 边框配合伪元素 `transform: scaleY(.5)`（或 `scale(.5)` 画四边）。**不要用 1rpx**，在部分安卓机上会消失或粗细不一。
- **控件描边用 1px**：次要按钮、输入框、步进器、卡片、未选 chip。颜色 `--c-line`；次要按钮描边用 `--c-ink`。
- 不用阴影。拖动排序中被拿起的卡片用 1px `--c-ink` 描边，并放大到 1.02 倍，表示浮起。

### 2.5 动效

- 时长：常规 200ms，弹层 250ms，曲线 `ease-out`。
- 勾选完成：勾选圆圈缩放 0.8→1，同时 `wx.vibrateShort({type:'light'})`。
- 不做装饰性动画；切月只做横向滑动过渡。

## 3. 微信框架适配

### 3.1 导航栏（全部页面 `navigationStyle: custom`）
- 状态栏高度用 `wx.getWindowInfo().statusBarHeight`；胶囊位置用 `wx.getMenuButtonBoundingClientRect()`。
- 导航栏高度 = `capsule.height + (capsule.top − statusBarHeight) × 2`；导航内容和胶囊垂直居中对齐。
- **胶囊避让**：导航栏内容右侧留出 `windowWidth − capsule.left + 16rpx`，所有可点元素都放在这条线左边。导航栏右侧**不放任何按钮**，编辑、删除等操作放到页面底部或「⋯」菜单里。
- tab 页（日历 / 动作库 / 身体数据）：左对齐大标题（48rpx，700），没有返回键。
- 二级页：左侧返回箭头（点击区 88×88rpx），标题居中 34rpx。录入页（新建训练、身体记录）左侧用「×」关闭。
- 建议做成一个公共 `nav-bar` 组件，由 Jarvis 实现。

### 3.2 tabBar（原生）
- 三项，**顺序：日历 / 动作库 / 身体数据**（现有 `app.json` 里是「日历 / 身体数据 / 动作库」，需要调整）。
- `color: #8C8C8C`，`selectedColor: #FF5A1F`，`backgroundColor: #FFFFFF`，`borderStyle: black`（显示顶部细线）。
- 图标：建议提供 81×81px 的线性 png 图标（日历 / 列表 / 折线），线宽 2px；如果 v1 来不及做图标，可以先只显示文字。
- 新建训练**不占 tab**：从日历页的悬浮按钮或选中某天后的按钮进入。

### 3.3 安全区
- 底部固定操作栏：`padding-bottom: calc(24rpx + env(safe-area-inset-bottom))`。
- tab 页的悬浮按钮放在 tabBar 上方 32rpx，右边距 32rpx；原生 tabBar 已处理安全区，悬浮按钮不需要再加。
- 二级页可滚动内容底部留出「操作栏高度 + 安全区」的空白，避免最后一项被遮住。

## 4. 组件规范

### 4.1 按钮
| 类型 | 样式 | 高度 | 用途 |
|---|---|---|---|
| 主按钮 | `--c-ink` 底、白字 32rpx/600、圆角 16rpx | 底部操作栏 112rpx；页内 96rpx | 每屏只有一个：完成训练、保存、添加到训练 |
| 次要按钮 | 白底、1px `--c-ink` 描边、黑字 | 同上 | + 动作、补录训练 |
| 幽灵按钮 | `--c-bg-2` 底、黑字 | 80rpx | 次要的页内操作 |
| 危险按钮 | 白底、1px `--c-line` 描边、`--c-danger` 字 | 96rpx | 删除这条记录、删除训练 |
| 文字按钮 | 无底，黑字 600（危险操作用红字） | 点击区 ≥ 88rpx | 「+ 加一组」「清除」「编辑」 |
| 悬浮按钮 FAB | 112rpx 圆，`--c-accent` 底，白色「+」线宽 5rpx | — | tab 页新建（日历：新建训练；身体数据：新增记录） |

状态：按下时透明度 0.7；禁用时底色 `#E5E5E5`、白字，不响应点击；提交中显示 loading 并防止重复点击。

### 4.2 列表项
- 高 96 / 120 / 136rpx，左右边距 32rpx；分割线为 hairline，左侧和文字对齐（不通栏）。
- 结构：[可选左侧占位块 80rpx] 主文字 32rpx + 次文字 24rpx 灰 → 右侧数值或说明 → chevron（`--c-placeholder`）。
- 可左滑的列表（身体记录）：左滑露出 160rpx 宽的红底「删除」。
- 分组标题：高 56rpx，`--c-bg-2` 底，24rpx 灰字 600，格式「胸 · 35」。

### 4.3 标签与 chip
- **标签 tag**（只展示，不可点）：高 40rpx，左右内边距 12rpx，圆角 8rpx，22rpx 字。
  - 实心黑 `solid`：目标肌群
  - 细线 `line`（1px `--c-ink`）：次要肌群、训练卡片上的部位
  - 浅灰 `gray`：状态（已完成 / 休息日）
  - 强调浅底 `accent`：草稿
- **chip**（可点、单选）：高 60rpx，圆角 999，左右内边距 24rpx，26rpx 字。未选：白底 1px `--c-line`、灰字；选中：黑底白字 600。多于一屏时横向滚动（`scroll-x`），不换行；筛选面板里可以换行。
- **分段控件 segmented**：`--c-bg-2` 底，圆角 16rpx，高 64rpx；选中项为白底，加 hairline 描边、黑字 600。用于「图表 / 日历」「30天 / 90天 / 全部」。

### 4.4 输入框与步进器
- **输入行**（表单）：高 112rpx，左边标签 32rpx，右边数值右对齐 40rpx/600，单位 28rpx 灰，固定在最右；底部 hairline。必填项在标签后加强调色 `*`。
  - 数值输入一律用 `type="digit"`，次数用 `type="number"`；获得焦点时底线变成 1px `--c-ink`。
  - 错误：底线变 1px `--c-danger`，下方 24rpx 红字说明；失焦或点保存时校验，**输入过程中不报错**。
- **搜索框**：高 72rpx，`--c-bg-2` 底，圆角 16rpx，左侧放大镜图标；输入后右侧出现清除按钮；`confirm-type="search"`，输入停止 300ms 后实时过滤。
- **步进器**（训练录入用，核心组件）：
  - 尺寸（2026-10-17 走查修正：原数值加起来 656rpx，超过卡片内宽 638rpx）：组行内各列 **固定宽度、`flex-shrink: 0`**，从左到右为：序号 72rpx、间距 8、重量步进器 240rpx、间距 8、次数步进器 200rpx、间距 8、勾选 88rpx，合计 624rpx（卡片左右内边距 24rpx，内宽 638rpx）。步进器高 **88rpx**，「− / +」按钮各 72rpx 宽，点击区就是整格高度；中间数字 34rpx/600。序号列点击区为 72×88rpx（热身组的灰底「热」只是视觉，点击区不缩小）。
  - 步长：重量 ±2.5kg、次数 ±1；长按 400ms 后开始连续加减（每 100ms 一次）。下限 0，上限：重量 999.9、次数 999（与 DATA_MODEL 一致）。
  - 点击中间数字：直接弹出数字键盘编辑（`type=digit` / `number`）。重量保留 1 位小数。
  - 空值显示「—」灰色；自重动作重量为空时显示「自重」。
- **勾选（完成）**：显示为 56rpx 圆，点击区 88×88rpx。未选：1.5px `#CCCCCC` 描边；已选：强调色实心圆加白色对勾。

### 4.5 卡片
- 白底，1px `--c-line` 描边，圆角 24rpx，内边距 32rpx，**无阴影**。
- **训练摘要卡**（日历页）：上部 3 列统计（数字 44rpx/700 + 22rpx 灰色说明），中间 hairline，下面最多列 3 个动作「名称 …… N组 · 最佳 Xkg×Y」，超过 3 个显示「等 N 个动作」。整卡可点。
- **训练动作卡**（录入页）：左右内边距 24rpx（比普通卡片小，为组行留宽度）；头部 112rpx：拖动把手 ≡、动作名 34rpx/700、部位 tag、右侧「⋯」（点击区 88rpx）；表头 22rpx 灰；组行高 104rpx；底部是「+ 加一组」文字按钮，整行可点，高 96rpx。可以折叠，折叠后只显示「N 组」。
- **草稿横幅**：`--c-accent-weak` 底，圆角 24rpx，无描边，右侧放强调色文字按钮「继续」。

### 4.6 日历
- 7 列等分，周一开头，表头 24rpx 灰；日期格高 88rpx（身体数据日历是 100rpx，因为要显示数值）。
- 日期的状态（同一格可以叠加）：

| 状态 | 表现 |
|---|---|
| 训练日（有已完成训练） | 数字下方 10rpx 处一个 10rpx 强调色实心圆点 |
| 休息日（过去的日子里没有已完成训练） | 只显示黑色数字，不加标记 |
| 选中日 | 68rpx 黑色实心圆，数字白色 700；如果也是训练日，圆点仍显示在圆外下方 |
| 今天 | 数字用强调色 700（被选中时变白色，靠「今天」按钮回来） |
| 未来日期 | 数字用 `--c-placeholder`，可以点（查看为空），但不能新建训练 |

- 草稿**不在日历上打点**（DATA_MODEL：日历只读 completed），用页面上的草稿横幅提示。
- 顶部：「2026年10月」34rpx/700 + 「今天」小胶囊 + 左右切月箭头；也可以左右滑动切月。下方一行图例（训练日 / 选中 / 今天）。
- 身体数据日历：有记录的日期，数字下方用 18rpx 灰字显示当天体重（没有体重时显示「•」）。

### 4.7 图表（折线）
- 用 canvas `type="2d"` 绘制（现有 `utils/chart.js` 方案），高 360rpx，左侧留 48rpx 放 Y 轴刻度。
- 网格：4 条水平线，上 3 条虚线（2/3）、底线实线，全部 hairline `--c-line`；**不画竖向网格**。
- Y 轴：自动取整（体重 1kg、体脂 1%、腰围 1cm 的整数倍），上下各留 10% 余量；刻度 20rpx `--c-text-3`。
- X 轴：最多 5 个日期刻度，格式「M/D」，均匀分布。
- 折线：2px `--c-accent`，折点 5px 白心强调色描边；最新的点 10px 实心，并加一条强调色细虚线做竖向参考线。
- 交互：手指点按或拖动 → 最近的点显示气泡（黑底白字「10月14日 · 69.0 kg」），松手 2 秒后消失。
- 数据点 0 个：显示空状态；1 个：只画这个点和它的数值，不画线；数据为 `null` 的日期跳过，不插值、不当 0。
- 当前值大字（80rpx）放在图表上方，下面一行 24rpx「10月17日 · 较上次 −0.6 kg」。差值只显示数字和正负号，**不用红绿色**（体重涨跌的好坏因人而异）。

### 4.8 空状态
- 结构：图标（96rpx 细线圆形占位）→ 30rpx 灰色主文案 → 24rpx 浅灰副文案（可省略）→ 次要按钮（可省略）。在可视区域内居中，整体上移 10%。
- 文案语气：平实、给出下一步，不卖萌、不用感叹号。各页面文案见第 5 节和 PRODUCT_SPEC。

### 4.9 反馈
- toast：黑底白字，圆角 16rpx，距底部操作栏 24rpx。**带「撤销」的 toast** 右侧放强调色文字按钮，停留 5 秒。
- 二次确认：`wx.showModal`，确认按钮用红色文字「删除」（`confirmColor: '#E5484D'`）。
- 底部操作菜单：`wx.showActionSheet`，危险项用红色字（`itemColor` 只能统一设置，所以危险项放在最后，靠文案区分）。

### 4.10 文字占位块 / 动作媒体区
- 动作库列表：80rpx 方块，圆角 16rpx，`--c-bg-2` 底，居中放动作名的后两个字（30rpx/600 `--c-text-2`），例如「卧推」「划船」。**列表不加载视频或封面缩略图。**
- 动作详情无媒体：通栏 240rpx 高的块，圆角 24rpx，`--c-bg-2` 底，居中放动作名后两个字（88rpx/700 `#D6D6D6`）。
- 动作详情有视频或线稿（当前视频试点 24，见 `data/VIDEO_PILOT_24.md`）：通栏 1:1 媒体区（约 686×686 rpx），圆角 24rpx，白底；视频见 `ILLUSTRATION.md` §7，线稿见同文档 §1–2。
- 回退顺序：视频失败 → 封面 / 线稿图 → 文字占位。不出现裂图或黑块。
- 不使用任何 openGym media 图片或视频，也不使用未授权外链。

### P1 日历首页
- 布局：大标题「训练」→ 月份栏 → 月历 → 图例 → hairline → 选中日区块（日期 34rpx/700 + 状态 tag + 时长）→ 训练摘要卡（同一天有多次训练时纵向排列）→ 悬浮按钮 → tabBar。
- 草稿横幅：只要存在草稿，就在选中日区块顶部显示「今天有一个未完成的训练 · 继续」（草稿日期不是今天时显示「10月15日有一个未完成的训练」）。
- 交互：点日期 → 选中，下方切换摘要；点摘要卡 → P2；悬浮按钮 → 为选中日新建训练（选中未来日期时悬浮按钮置灰，点击提示「不能为未来日期新建训练」）。
- 空状态：选中的过去日期没有训练 → 「这天没有训练 / 休息也是训练的一部分 / [补录训练]」；选中今天且没训练 → 「今天还没有训练 / [开始训练]」；选中未来日期 → 只显示「还没到这一天」，没有按钮。

### P2 训练详情（已完成）
- 布局：返回 →「10月15日 周四」48rpx + 「已完成」tag → 「18:30 开始 · 62 分钟」（补录的训练没有开始时间，显示「补录」）→ 3 列统计 → 每个动作一段：动作名 + 部位 tag、表头「组 / 重量 kg / 次数 / 容量」、组行（热身组序号显示灰底「热」，未打勾的组整行变浅并标「未完成」）→ 训练备注 → 底部操作栏：[删除]（危险，宽 200rpx）+ [编辑训练]（主按钮）。
- 名称：有 `name` 时显示在日期上方（26rpx 灰），没有就不显示。
- 点动作名 → P6。

### P3 新建 / 编辑训练（单手录入）
- 顶部导航：左「×」；中间是训练日期「10月17日 周六 ▾」（点开「训练信息」面板，可改名称、日期、备注）；状态 tag「草稿」+「已自动保存」小字（编辑已完成的训练时显示「已完成」tag）。
- 主体：动作卡纵向排列（见 4.5），当前正在练的动作展开，其他折叠；组行：序号（点击切换 普通 / 热身）+ 重量步进器 + 次数步进器 + 完成勾选。
- **拇指区**：底部操作栏 112rpx 高的按钮：[+ 动作]（次要，240rpx 宽）+ [完成训练]（主按钮，占满剩余宽度）。编辑已完成训练时变成 [+ 动作] + [完成编辑]（两种模式都即时保存）。
- 次要操作（不放进拇指热区，避免误触）：「⋯」菜单（动作备注 / 调整顺序 / 替换动作 / 删除动作）、长按组行打开菜单（设为热身组 / 在下方复制一组 / 删除此组）、左滑组行删除。
- 排序：「⋯ → 调整顺序」进入排序模式（线框 05），动作卡折叠成 112rpx 高的行，按住右侧把手拖动；不在排序模式时，长按卡片标题 300ms 也可以直接拖动。
- 空状态：还没有动作 → 页面中部显示「从动作库添加第一个动作」+ 大号次要按钮 [+ 添加动作]（放在屏幕下半部）。

### P4 动作选择器
- 布局：返回 + 标题「选择动作」→ 搜索框 → 肌群 chip 行 → 器械 chip 行（横向滚动）→ 列表（名称 + 「部位 · 器械」+ 右侧「详情」文字按钮 + 勾选圆）→ 底部操作栏「已选 N 个」+ [添加到训练 (N)]。
- 点整行切换勾选；点「详情」→ P6（详情页底部按钮变成「选择这个动作」）。
- 已在本次训练中的动作显示「已添加」小标签，**仍然可以再选**（DATA_MODEL 允许重复引用）。

### P5 动作库
- 布局：大标题「动作库」+ 数量（「共 284 个」，筛选后显示「共 45 / 284」）→ 搜索框 → 两个下拉 chip「肌群：全部 ▾」「器械：全部 ▾」+「清除」→ 按部位分组的列表（分组顺序按 filters.json 里 bodyPart 的顺序）。
- 列表项：80rpx 文字占位块 + 中文名 32rpx/600 + 英文名 24rpx 灰 + 右侧「器械 · 类别」+ chevron。
- 筛选面板（线框 08）：底部弹层，「肌群（部位）」6 项 + 「器械」13 项，全部来自 `data/filters.json`，单选；底部主按钮实时显示「查看 N 个动作」。
- 空状态：「没有找到“xx” / 试试其他关键词，或清除筛选 / 清除筛选」。

### P6 动作详情
- 布局：返回 → **视频 / 线稿 / 文字占位** → 中文名 56rpx/700 → 英文名 28rpx 灰（首字母大写显示）→ 「目标肌群」solid tag +「次要肌群」line tags（中文名查 filters.json 的 `muscles`）→ hairline → 2×2 信息格（部位 · 细分 / 器械 / 类别 / 我的最佳）→ hairline → 「动作步骤」：序号「01」用强调色 30rpx/700，步骤 28rpx 行高 1.6，全部展开。
- 有 `video`（试点 24）：1:1 `<video>`，`autoplay` + `loop` + `muted`，无控件，`poster` 必设，点击暂停/继续，右下角 48rpx 细线圆提示播放状态；离开页或切后台暂停。见 `ILLUSTRATION.md` §7。
- 无视频但有 `illustration`：显示 1:1 线稿，见线框 14。视频失败 → 封面/线稿 → 文字占位（§4.10）。
- `translationPending` 的动作：步骤显示英文原文，标题旁加 gray tag「暂无中文」。`description` 全是英文，v1 不展示。
- 底部操作栏：[加入当前训练]。有草稿 → 加到草稿末尾，toast「已加入当前训练」+「去查看」；没有草稿 → 新建今天的草稿，加入后直接跳到 P3。从选择器进来时按钮是「选择这个动作」。
- 「我的最佳」：只统计已完成训练里打勾的正式组中最大的重量（显示「60kg × 8」）；没有记录时显示「—」。

### P7 身体数据
- 共同部分：大标题 → 分段「图表 / 日历」（记住上次的选择）→ 悬浮按钮（新增记录）→ tabBar。
- **图表视图**（线框 10）：指标 chip「体重 / 体脂率 / 腰围」→ 当前值大字 + 较上次 → 右侧分段「30天 / 90天 / 全部」→ 折线图 → 「记录」列表（最近 3 条，「全部 ›」进入完整列表，左滑删除，点击编辑）。
- **日历视图**（线框 11）：月历，有记录的日期下方显示体重 → 选中日的卡片（体重 / 体脂率 / 腰围三格，空值显示「—」，右上角「编辑」）→ 选中没有记录的过去日期时显示 [补录这天]。
- 空状态：没有任何记录 → 「记录第一次体重，开始看趋势」+ [记录体重]；有记录但当前指标没有数据 → 「还没有腰围记录」+ [去记录]。

### P8 新增 / 编辑身体数据
- 布局：返回 + 标题「记录身体数据」（编辑时为「编辑记录」）→ 日期行（picker，`end` = 今天）→ 体重 * / 体脂率 / 腰围（单位 kg / % / cm 固定显示）→ 备注 → 底部操作栏 [保存]；编辑时下面再加 [删除这条记录]。
- 打开时自动聚焦体重输入框，弹出数字键盘；键盘弹起时操作栏顶在键盘上方（`adjust-position`）。
- 选择的日期已有记录 → 自动载入那天的记录，转为编辑，并 toast「已载入 10月14日 的记录」。
