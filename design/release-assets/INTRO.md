## A. 服务简介（推荐，约 68 字）

```
组迹是本地健身训练记录工具：记下每次训练的动作、组数、次数和重量，按日历回看；记录体重、体脂率和腰围并看趋势；内置动作库。数据只保存在本机。
```

## B. 精简版（约 40 字）

```
记录力量训练的组、次和重量，按日历回看，顺便记体重趋势；内置动作库，数据只存本机。
```

## C. 资料页一句话（约 22 字）

```
本地记录每一次训练和身体数据，留下你的组迹。
```

## D. 提审补充说明（可选，约 90 字）

```
组迹用于个人力量训练记录：支持训练日历、训练录入（组/次/重量）、身体数据图表、动作库查询。无账号、无网络请求、无社交分享；训练与身体数据仅保存在用户本机。动作库文字数据来自 openGym（AGPL-3.0），示意为自制线稿。
```
