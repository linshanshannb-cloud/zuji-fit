## 3. 截图是怎么做的

- **样式直接取自真实代码**：`gen_screens.py` 读取 `miniprogram/app.wxss` 和各页面、组件的 `.wxss`，按 375 宽换算 rpx→px（1rpx = 0.5px），并按组件作用域加前缀。DOM 按对应的 `.wxml` 结构手写。
- **图表**：`line-chart` 的 canvas 绘制逻辑，以及 `utils/repo/series.js` 的 `niceScale`/`chartLayout`，都 1:1 移植到页面脚本里。
- **系统部分是模拟的**：状态栏 9:41、微信胶囊（iPhone X 参数：状态栏 44px，胶囊 top 48 / 高 32 / left 281）、原生 tabBar（使用 `miniprogram/images/tabbar/` 下的真实图标）、Home 指示条和底部安全区 34px，都是按这些参数画出来的。
- **渲染方式**：无头 Chrome，`--force-device-scale-factor=3`。字体用 Noto Sans CJK SC 代替苹方，真机上的字形会略有不同。
- **动作详情页**：截图略向下滚动了 76px，让“我的最佳”一行完整露出。插图是项目自制线稿，与 openGym 媒体无关。

## 5. C 系列头像（2026-10-19 18:01 北京时间新增，按 Shanshan 的反馈）

- 反馈：保留方案 B 的橙底（#FF5A1F 底配白色图形），但 B 看起来像网络信号格，需要改成“半边杠铃”，杠铃片由小到大、节节高。
- 三个方案共有的元素：可见的杆端或滚花握把、卡箍/套筒，以及 3 片圆角杠铃片。杠铃片由矮到高、由薄到厚，片与片之间留缝。
- 圆形裁切校验：在 1024 PNG 上测量，所有白色像素距中心不超过 401px，而圆形裁切半径是 512px，所以裁成圆形时图形不会被切到。`gen_avatar_c.py` 会自动居中并缩放到这个安全半径。
- C2 说明：杠铃片竖直放置、横杆斜穿片心的版本试做过，看起来像“柱状图加折线”，所以没有采用。现版本让整根杆倾斜、杠铃片垂直于杆，同时保持 3 片的最低点对齐在同一条地面线上。
- 小尺寸表现：44px 下，横杆上的滚花会糊成细纹，但不影响识别。C3 的环线细节最多，小尺寸下最“碎”。

## 6. 头像定稿（2026-10-19 18:06 北京时间，Shanshan 选定 C1）

- **改动 1**：右侧横杆从 352 缩短到 224（C1 原始坐标），滚花随之缩短。杠铃片、套筒和卡箍不变。
- **改动 2**：整个图形（杆端、杠铃片、卡箍、横杆）按实际像素边界在画面中居中，而不是按杠铃片居中，所以杠铃片会略偏左，以保证左右留白相等。缩放后，图形离画布中心最远约 400px。
- **测量结果**（1024 版 PNG，白色像素逐像素统计）：
  - 图形边界：x 111–912，y 216–807，即 802×592px。
  - 留白：左 111px、右 111px，上 216px、下 216px。
  - 图形距画布中心最远 400.6px。圆形裁切半径是 512px，最近处仍有约 111px 余量。
  - 半径 500px 以外没有任何非橙色像素，裁成圆形时不会切到图形。
- **出图方式**：SVG 由 `src/gen_avatar_final.py` 生成，PNG 用无头 Chrome 渲染，RGB 无透明通道，均远小于 2MB。
