## 1. 风格

| 项 | 规定 |
|---|---|
| 画风 | 极简线稿示意图，白底、单色描边，无填充色块（除可选浅灰辅助线） |
| 描边色 | `#111111`，线宽视觉约 2–3px（导出后按分辨率缩放） |
| 强调色 | **默认不用** `#FF5A1F`；仅在「起 / 止」双帧示意图中可用橙色小箭头标运动方向 |
| 背景 | 纯白 `#FFFFFF`，无渐变、无阴影、无纸张纹理 |
| 人物 | 简化几何人形（圆头 + 躯干四肢），无五官、无发型、无性别特征、**无肌肉写实** |
| 器械 | 简化几何：杠铃=横杆+两侧圆片；哑铃=短杆+两端圆；绳索=把手+虚线缆 |
| 禁止 | 照片、3D 写实、漫画阴影、水印、文字标注（图内不写动作名）、背景场景 |

---

## 2. 构图

- **画幅**：正方形，导出 **750×750 px**（@2x，对应界面约 343×343 pt / 686×686 rpx 通栏区）。
- **留白**：主体四周至少 8% 边距，不贴边。
- **视角**：默认 **侧面或 3/4 侧面**；对称推类（卧推、肩推）可用正面略俯视；平板类用侧面。
- **姿态**：画动作的 **稳定中位或底部位置**（最能辨认动作的一帧）；需要展示行程时出 **起止双帧**（左右并排，中间小箭头），仍算一张导出图。
- **左右**：面向画面时，惯用侧肢体在右侧（便于右利手镜像理解）；左右不对称动作（侧平板、保加利亚）必须与步骤文案一致。
- **安全**：脊柱中立示意、膝盖不超过过分前移、杠铃轨迹不过分偏离；明显危险姿势一律重画。

## 3. 文件与字段（建议）

| 项 | 约定 |
|---|---|
| 路径 | `miniprogram/assets/exercises/{id}.png`（或 `.webp`，优先体积） |
| 命名 | 与动作 `id` 一致，四位补零，如 `0025.png` |
| 体积 | 单张 ≤ 40KB（线稿 PNG/WebP）；20 张合计建议 ≤ 600KB，走 **分包** 或按需下载，勿塞满主包 2MB |
| 字段 | 在动作对象上增加可选 `illustration?: string`（相对 `miniprogram/` 的路径）；**无此字段 = 无图** |
| 许可 | 自生成示意图，归项目使用；`DATA_NOTES.md` 注明来源为「自研线稿示意图」，与 openGym media 无关 |

字段扩展示例（由动作库管家落地，改前先告知 Jarvis）：

```json
{
  "id": "0025",
  "nameZh": "杠铃卧推",
  "illustration": "assets/exercises/0025.png"
}
```

## 7. 视频方案（封面 + 云存储循环播放，0.3.0）

> 工程与踩坑细节以 `docs/动作视频-云存储播放手册.md` 为准。本节只定**界面交互与视觉**；有氧若上云视频，沿用同一套。

| 项 | 规定 |
|---|---|
| 来源 | Shanshan 提供的自生成视频（云端已传 58 段量级，以数据侧为准）；不使用 openGym media |
| 文件 | 云路径 `anim/<id>.mp4`；封面主包 `assets/video-posters/<id>.jpg` |
| 规格 | 约 5 秒、静音、无缝循环；1:1 或居中裁成 1:1，短边约 480px；H.264（yuv420p，moov 在前） |
| 投放 | **视频只放云存储**，详情页 `getTempFileURL` → https 给 `<video src>`；**禁止**再写分包 / `packageVideo*` / `loadSubpackage` / 代码包本地路径。封面 jpg 仍放主包（注意主包 2MB） |
| 字段 | 可选 `video`（完整 `cloud://…` fileID）、`poster`（主包相对路径）；无字段 = 无视频 |

详情页（P6）：
1. 顶部 1:1 媒体区（686×686rpx，圆角 24rpx，白底），沿用线框 14 的位置。
2. 进详情：先显示主包封面（或线稿）；拿到 https 临时地址后切 `<video>`；`autoplay` + `loop` + `muted`，`show-controls=false`、不显示全屏/进度/音量，`object-fit="contain"`，`poster` 用主包路径，避免加载前黑块/空白。
3. 点击媒体区：暂停 / 继续；取址或播放失败停在封面上时，点击应触发重试。右下角 48rpx 细线圆形图标提示播放状态，不加其他装饰。
4. 回退顺序：视频失败 → 主包封面 / 线稿；再失败 → §4.10 文字占位。不出现裂图或黑块。
5. 离开页面或切后台时暂停；省流/弱网下首帧前只显示主包封面。
6. 列表页（P5）仍不加载视频或封面缩略图。

封面：从视频截最能看清动作的一帧（不一定是第一帧，避开空镜/过渡），白底优先，750×750 JPG，≤40KB。

验收补充：姿势安全、左右与步骤一致；循环衔接无跳帧；断网/坏路径回退封面再回退文字占位。真机以 iOS `<video>` + https 为准，不以模拟器 `MEDIA_ERR_*` 为准。
