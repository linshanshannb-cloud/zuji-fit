# 自定义动作与动作库导航

日期：2026-10-25（Asia/Shanghai）

## 目标

1. 放开自定义动作（名称 + 训练部位），可在动作库看到并选入力量训练。
2. 动作库 / 选择器部位菜单固定高度：切部位不必滚回顶部。

## A. 自定义动作

### 底层（原有，未改语义）

- 存储键：`fit_custom_exercises`（`utils/repo/keys.js` → `CUSTOM`）
- API：`addCustom` / `updateCustom` / `deleteCustom` / `listCustom` / `healCustom`
- 自定义排在内置动作之前；`all()` / `filter()` / `get()` 已合并

### 新增 UI

| 入口 | 行为 |
|------|------|
| 动作库导航栏「+ 自定义」 | 打开新建表单 |
| 动作选择器搜索区旁「+ 自定义」 | 同上（选完可再勾选） |
| 动作库左侧「我的」 | 仅自定义；有自定义时才出现 |
| 卡片角标「自定」 | 橙色 `#FF5A1F` |
| 详情页（自定义） | 编辑 / 删除 / 加入训练 |

### 表单字段

- **必填**：名称（≤30）、训练部位（胸/背/肩/手臂/腿/臀/核心）
- **可选**：器械（默认自重）；模型已支持的 description/steps 等本次未放开，避免表单过重
- 部位映射见 `utils/custom-part.js`：**臀** = `bodyPart=legs` + `target=glutes`（与 `muscle.groupOf` 一致，归入「臀」侧栏）

### 删除策略（沿用现有 repo）

- 若该动作已被任意训练记录引用 → **归档**（`archived: true`），动作库隐藏，历史记录仍显示原名
- 若无引用 → **硬删除**
- UI 文案会提示上述规则；归档后不可再加入新训练（`ARCHIVED_EXERCISE`）

### 数据边界

- 仅本地 `wx` 存储；不写云开发用户库
- 不改视频播放链路、有氧、日历首屏

## B. 动作库导航（高度固定）

- `library` / `exercise-picker` 设置 `disableScroll: true`
- 顶部搜索/筛选固定；下方左右分栏用 `scroll-view`，高度 = `windowHeight - 顶部底边`（选择器再扣底栏）
- 左侧部位栏始终可见；右侧列表单独滚动
- 切换部位时 `scroll-top` 复位（0 / 0.01 翻转），列表回顶

- 新增：`pages/custom-exercise-edit/*`、`utils/custom-part.js`、`tests/custom-part.test.js`、本文档
- 修改：`app.json`、`utils/card.js`、`pages/library/*`、`pages/exercise-picker/*`、`pages/exercise-detail/exercise-detail.{js,wxml}`

## 自测建议

1. 动作库 → + 自定义 → 填名称选「臀」→ 保存 → 「我的」与「臀」均可见，角标「自定」
2. 新建力量训练 → 选择动作 → 勾选自定 → 保存训练
3. 详情 → 编辑改名 → 返回详情名称已更新
4. 删除未引用动作 → 消失；删除已引用 → Toast「已归档」，历史仍可见
5. 选「胸」滚到底 → 点「背」：侧栏仍在、列表回顶
