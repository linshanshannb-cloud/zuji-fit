# 发布前真机手动验证清单（v1，个人主体）

> 自动化已覆盖：单元测试、页面冒烟、对抗用例、miniprogram-simulate 页面测试、7 时区矩阵、开发者工具自动化（76/76）。
> 以下是**自动化测不到、必须在真机上人工过一遍**的项目。建议至少 1 台 iPhone + 1 台安卓；有条件加一台 iPhone SE（320pt 宽）。
> 测前：开发者工具「预览」扫码，或上传为体验版后在手机打开。每项记录 ✅/❌ + 机型 + 微信版本。

## A. tabBar 与导航
| # | 怎么测 | 预期 |
|---|---|---|
| A1 | 打开小程序，看底部 3 个 tab（日历 / 动作库 / 身体数据） | 每个 tab 有图标：未选中灰色、选中橙色 #FF5A1F，图标清晰不糊、不变形，文字不被遮挡 |
| A2 | 依次点 3 个 tab | 图标颜色随选中切换；页面正确；无白屏 |
| A3 | 每个页面看顶部自定义导航栏 | 标题不与右上角胶囊重叠；返回按钮可点；刘海/灵动岛机型状态栏不被遮挡 |

## B. 训练记录（步进器、输入）
| # | 怎么测 | 预期 |
|---|---|---|
| B1 | 新建训练→加动作→在某组「重量」上**单击** + / − | 每次 ±1 步长，数值即时变化 |
| B2 | **长按** + 不放约 2 秒，然后松手 | 数值以约每 0.1 秒一次连续递增；松手立即停止，不会继续跳；松手后数值被保存（退出再进仍是该值） |
| B3 | 长按 − 直到 0 附近 | 不出现负数；停在下限 |
| B4 | 长按过程中手指滑出按钮再松开 | 连续增减能停止（若不停止 = ❌，记录机型） |
| B5 | 点数字直接键盘输入，含小数（如 62.5）、非法值（空、字母、超大数） | 小数重量保留；非法输入有提示/抖动，不写入脏数据 |
| B6 | 勾选「完成」圆圈；长按一组行 | 勾选有动画并标橙；长按弹出组操作菜单，不误触发步进器 |
| B7 | 软键盘弹出时 | 输入框不被键盘遮住，底部操作栏位置正常 |

## C. 身体数据图表
| # | 怎么测 | 预期 |
|---|---|---|
| C1 | 录入 ≥3 天不同体重，打开身体数据页 | 折线图正常绘制、不糊（高清屏）；坐标轴标签不重叠 |
| C2 | **点击**图上某个点 | 出现黑色气泡 tooltip 显示日期/数值，约 2 秒后自动消失 |
| C3 | 在图上**左右拖动** | 气泡跟随最近的点；在最左/最右端点时气泡不超出图表边界 |
| C4 | 只有 1 条记录 / 0 条记录 | 1 条：显示单点+数值；0 条：显示空状态，不报错 |
| C5 | 切换时间范围分段（如 30 天/90 天等） | 图表重绘正确，无残影 |
| C6 | 打开图表后上下滚动页面 | canvas 不错位、不浮在其他元素之上（同层渲染问题） |

|---|---|---|
| D1 | 训练编辑页：一组「序号 + 重量步进器 + 次数步进器 + 完成」 | 一行放得下，不换行、不横向溢出，+/− 仍好点（不小于手指） |
